# Northview College – Website Home Page

## 📌 Project Description
This project is a simple and responsive **College Website Home Page** created using **HTML and CSS**.  
It demonstrates a professional layout suitable for educational institutions.

## 🧩 Features Implemented
- Header with college logo, name, navigation links, and Apply Now button
- Explore Our College section with three informational blocks
- Event highlights section with a View All Events button
- Footer with quick links, social media icons, and contact details

## 🛠 Technologies Used
- HTML5
- CSS3
- Font Awesome Icons

## ▶️ How to Run
1. Download or copy the files.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in any web browser.

## 🎯 Outcome
A clean, professional, and user-friendly college homepage design suitable for academic assignments and exams.
